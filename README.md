# NodOne Tools — Releases

This repository hosts release artifacts for **NodOne Tools**.

Each GitHub Release here contains the Windows installer and its SHA-256:
`NodOneTools-Setup-vX.Y.Z.exe`, `NodOneTools-Setup-vX.Y.Z.exe.sha256`

NodOne Suite reads its signed list (`suite.json` in nodone-suite-releases) and installs updates from here.
